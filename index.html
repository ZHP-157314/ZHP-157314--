二、什么是创客

创客（Maker）是指一群酷爱科技、热衷实践、乐于分享，努力把各种创意转变为现实的人。创客运动的核心理念是"动手创造、分享协作"。

创客运动的起源与发展

创客运动（Maker Movement）起源于2005年左右，随着Arduino、3D打印等开源硬件的普及而迅速发展。2012年美国《连线》杂志主编Chris Anderson出版《创客：新工业革命》，标志着创客文化正式进入主流视野。如今，全球各地的创客空间（Makerspace/Fab Lab）已超过2000个，为创客提供了交流、学习和协作的平台。

创客的核心特征

  • 动手实践：不只是理论学习，更强调亲手制作和实验。创客信奉"做中学"（Learning by Doing），通过实际操作来验证想法
  • 开源共享：乐于分享自己的设计、代码和经验。开源文化是创客运动的基石，GitHub、Thingiverse等平台让知识共享变得便捷
  • 跨界融合：结合电子、编程、设计、艺术等多学科知识。创客项目往往需要跨领域的技能组合
  • 迭代创新：不断测试、改进、优化产品原型。快速原型（Rapid Prototyping）是创客的核心方法论
  • 问题导向：从实际问题出发，寻找创新解决方案。好的创客项目都源于真实的用户需求

创客与传统制造的区别

维度 传统制造 创客模式
规模 大规模批量生产 小批量、个性化定制
门槛 需要大量资金和设备 低成本工具即可开始
知识 专业化分工 跨学科综合能力
协作 企业内部团队 全球开源社区

  • 硬件开发：Arduino、ESP32、Raspberry Pi、STM32等微控制器/单板计算机
  • 3D制造：FDM/SLA 3D打印机、激光切割机、CNC雕刻机
  • 电子工具：电烙铁、万用表、示波器、面包板

  • 协作平台：GitHub/Gitee（代码）、Thingiverse（3D模型）、立创EDA（PCB）

三、Git版本控制

Git是一个分布式版本控制系统，由Linux之父Linus Torvalds于2005年开发，用于跟踪代码变更、协作开发。在创客项目中，Git帮助我们管理代码版本、记录开发历程、实现团队协作。

为什么需要版本控制？

  • 历史追溯：记录每次修改的内容、时间和原因，随时可以回退到任意版本
  • 团队协作：多人同时修改同一项目时，自动合并不同人的修改
  • 分支管理：可以创建独立的开发分支，不影响主分支的稳定性
  • 备份恢复：代码托管到云端，防止本地数据丢失

Git核心概念

概念 说明
工作区（Working Directory） 项目文件所在的目录，直接编辑的文件
暂存区（Staging Area） 准备提交的文件快照，通过git add添加
本地仓库（Local Repository） 通过git commit提交的版本历史
远程仓库（Remote Repository） 托管在Gitee/GitHub上的代码仓库

四、3D设计与3D打印

3D设计与打印是创客实践的重要环节，通过数字化建模将创意转化为实物。本课程学习了Fusion 360建模软件和FDM 3D打印技术。3D打印技术（又称增材制造）通过逐层堆积材料的方式来构建三维实体，与传统的减材制造（如切削加工）相比，具有成型灵活、材料浪费少、适合小批量定制等优势。

SLS 激光烧结粉末 尼龙/金属粉末 ±0.1mm 功能性零件、工业件

Fusion 360建模流程

Step 1：创建草图

在XY平面上绘制2D轮廓，使用线段、圆弧、矩形等工具，添加尺寸约束和几何约束

Step 2：实体特征

通过拉伸（Extrude）、旋转（Revolve）、扫掠（Sweep）、放样（Loft）等操作将草图转换为3D实体

Step 3：布尔运算

使用合并（Union）、减去（Subtract）、相交（Intersect）组合多个实体，实现复杂结构

Step 4：细节处理

添加圆角（Fillet）、倒角（Chamfer）、抽壳（Shell）等特征，完善模型细节

Step 5：导出STL

将模型导出为STL格式文件，用于切片软件处理

FDM打印关键参数

参数 说明 推荐值
层高（Layer Height） 每层的厚度，影响精度和打印速度 0.2mm（标准）/ 0.1mm（精细）
壁厚（Wall Thickness） 外壳的厚度，影响强度 0.8-1.6mm（2-4圈）
填充率（Infill） 内部填充密度，影响强度和重量 15-20%（一般）/ 50%+（高强度）
打印温度 喷嘴和热床温度，影响层间粘合 PLA: 200°C/60°C, ABS: 240°C/100°C
打印速度 喷嘴移动速度，影响质量和时间 40-60mm/s（质量优先）
支撑类型 悬垂结构的支撑方式 树状支撑（易去除）/ 普通支撑（稳定）

遇到的问题与解决

  • 问题1：打印尺寸偏差 → 原因：材料热收缩、打印机精度误差 → 解决：在Fusion 360中调整模型参数，增加0.2-0.5mm补偿值
  • 问题2：支撑结构产生毛刺 → 原因：树状支撑与模型接触面积大 → 解决：改用普通自动支撑，后期用剪刀和砂纸修剪打磨
  • 问题3：打印翘边 → 原因：底面冷却不均匀 → 解决：调整热床温度至60°C，使用brim底座增加附着力
  • 问题4：层间开裂 → 原因：打印温度过低或速度过快 → 解决：提高喷嘴温度5-10°C，降低打印速度

五、电子焊接

电子焊接是电子制作的基础技能，通过加热使焊锡熔化，将电子元件连接成完整的电路。焊接质量直接影响电路的可靠性和使用寿命，是每个创客必须掌握的基本功。

焊接工具认识

工具 用途 注意事项
电烙铁 加热焊锡，提供焊接热源 温度控制在300-380°C，不用时放置在烙铁架上
焊锡丝 含锡合金，熔化后形成焊点 常用Sn63/Pb37（有铅）或SAC305（无铅）
助焊剂（松香） 去除氧化层，帮助焊锡流动 焊接后需清洗残留，防止腐蚀
吸锡器/吸锡带 去除多余焊锡，修正焊点 焊点加热后快速使用
剪线钳 剪切元件引脚和导线 剪切时注意保护眼睛
万用表 检测通断、电压、电阻 焊接前后都要检测电路

焊接四步法

Step 1：准备

清洁烙铁头（用湿海绵擦拭），给烙铁头上锡（镀锡），确保元件引脚和焊盘清洁

Step 2：加热

将烙铁头同时接触焊盘和元件引脚，加热约1-2秒，使两者温度均匀上升

Step 3：送锡

从另一侧将焊锡丝靠近焊盘，焊锡会自动熔化并流动，形成焊点后移开锡丝

Step 4：移开烙铁

焊锡充分流动后，沿引脚方向移开烙铁，等待焊点冷却凝固（约2-3秒）

焊点质量判断

焊点类型 外观特征 原因分析 解决方法
✅ 良好焊点 表面光亮、圆锥形、与焊盘充分润湿 温度合适、操作正确 无需处理
❌ 虚焊 表面暗淡、呈球状、与焊盘不润湿 温度不够或加热时间不足 重新加热焊接
❌ 冷焊 表面粗糙、有裂纹 焊点凝固时受到移动 重新加热，冷却时保持静止
❌ 过焊 焊锡过多、呈 blob 状 送锡过多或加热过久 用吸锡器去除多余焊锡
❌ 桥接 两个焊点之间有焊锡连接 送锡过多或焊盘间距太近 用吸锡带去除多余焊锡

安全规范

  • 通风环境：焊接产生的焊烟含有有害物质，需在通风良好处操作或使用排烟风扇
  • 防烫伤：烙铁头温度超过300°C，避免触碰；使用烙铁架放置不用的烙铁
  • 眼部保护：剪切引脚时注意保护眼睛，避免金属碎屑飞溅
  • 用电安全：焊接前确认电路断电，避免短路
  • 清洁习惯：焊接后洗手，避免接触食物

焊接实践

通过实际焊接练习，掌握了以下技能：

  • 通孔元件焊接：电阻、LED、排针、电容等直插元件的焊接
  • 导线焊接：导线与导线、导线与焊盘的连接
  • 焊点质量检查：目视检查焊点外观，用万用表检测通断
  • 返修技能：使用吸锡器和吸锡带修正不良焊点
  • 电路板组装：按照原理图完成简单电路板的焊接组装

六、嵌入式计算

嵌入式计算是创客项目的核心技术之一，通过微控制器（MCU）实现硬件的智能控制。与通用计算机不同，嵌入式系统是为特定任务设计的专用计算系统，具有体积小、功耗低、实时性强等特点。本课程主要学习了ESP32开发板的使用。

GPIO引脚详解

GPIO（General Purpose Input/Output）是微控制器与外部世界交互的基础。通过编程控制引脚的电平高低，实现对外设的控制和数据读取。

// GPIO基础操作示例

// 数字输出 - 控制LED
pinMode(2, OUTPUT);               // 设置引脚为输出模式
digitalWrite(2, HIGH);            // 输出高电平（3.3V）
digitalWrite(2, LOW);             // 输出低电平（0V）

// 数字输入 - 读取按键
pinMode(4, INPUT_PULLUP);         // 设置引脚为输入，启用内部上拉电阻
int val = digitalRead(4);         // 读取引脚电平：HIGH或LOW

// 模拟输入 - 读取传感器
int sensorVal = analogRead(34);   // 读取ADC值：0-4095
float voltage = sensorVal * 3.3 / 4095;  // 转换为电压值

// PWM输出 - LED调光
ledcAttach(2, 5000, 8);           // 通道0，频率5kHz，8位分辨率
ledcWrite(2, 128);                // 占空比50%（128/255）

Arduino IDE开发

Arduino IDE是创客最常用的嵌入式开发环境，语法基于C/C++，提供了丰富的库函数和示例代码。

// ESP32基础示例：LED闪烁
#define LED_PIN 2

void setup() {
    // 初始化函数，上电后运行一次
    Serial.begin(115200);         // 初始化串口，波特率115200
    pinMode(LED_PIN, OUTPUT);     // 设置LED引脚为输出
}

void loop() {
    // 主循环函数，反复执行
    digitalWrite(LED_PIN, HIGH);  // 点亮LED
    Serial.println("LED ON");    // 串口打印
    delay(1000);                  // 延时1秒

    digitalWrite(LED_PIN, LOW);   // 熄灭LED
    Serial.println("LED OFF");
    delay(1000);
}

Arduino程序结构

  • setup()：初始化函数，上电后只运行一次，用于配置引脚模式、初始化串口、连接WiFi等
  • loop()：主循环函数，setup()完成后反复执行，是程序的主体逻辑
  • 库的使用：通过#include引入库，使用库提供的函数简化开发（如WiFi.h、Wire.h等）

八、PCB设计

PCB（Printed Circuit Board，印刷电路板）设计是电子制作的进阶技能。与面包板和洞洞板相比，PCB具有可靠性高、体积小、适合批量生产等优势。通过专业EDA软件设计电路板，可以实现电路的规范化和小型化，是产品从原型走向量产的必经之路。

PCB基础知识

概念 说明
层数 单层板（低成本）、双层板（最常用）、四层板（高密度）
铜箔厚度 1oz（35μm）为标准，2oz用于大电流场景
线宽/线距 最小线宽/线距决定制造精度，一般6/6mil以上
过孔（Via） 连接不同层的金属化孔，分为通孔、盲孔、埋孔
焊盘（Pad） 元件引脚的焊接区域，分为直插焊盘和表贴焊盘
丝印层 印刷在PCB表面的文字和图案，用于标识元件

PCB设计流程

Step 1：原理图设计

使用EDA软件绘制电路原理图，放置元件符号，连接电气网络。原理图是电路的逻辑表达，与实际物理布局无关

Step 2：封装选择

为原理图中的每个元件指定PCB封装（Footprint），封装定义了元件的物理尺寸和引脚位置

Step 3：PCB布局

将原理图转换为PCB布局，合理安排元件位置。布局原则：信号流向清晰、发热元件分散、接口元件靠边

Step 4：布线

连接各元件的电气走线。布线原则：走线尽量短、避免直角转弯、电源线加宽、信号线远离干扰源

Step 5：DRC检查

运行设计规则检查（Design Rule Check），确保没有间距违规、未连接网络等错误

Step 6：生成Gerber

导出Gerber生产文件（包含各层的铜箔、阻焊、丝印等信息），送PCB工厂打样

PCB设计规范与技巧

  • 布局原则：按信号流向安排元件，输入在左、输出在右；发热元件远离敏感器件；接口元件放在板边
  • 布线原则：走线尽量短且直；避免90°直角弯（用45°或圆弧）；电源线加宽（≥20mil）；信号线间距≥2倍线宽
  • 电源处理：大电流路径使用铺铜（Polygon Pour）；退耦电容靠近IC电源引脚放置
  • 接地处理：模拟地和数字地单点连接；大面积铺地减少地阻抗
  • 丝印规范：元件标号清晰可读；极性元件标注方向；添加版本号和日期

PCB打样流程

  1. 导出Gerber文件：从EDA软件导出各层生产文件
  2. 选择PCB厂商：嘉立创、捷配、华秋等（嘉立创5元/5片，最快24小时出货）
  3. 上传下单：上传Gerber文件，选择板厚、颜色、数量等参数
  4. 收到PCB：检查外观质量，使用万用表检测关键网络通断
  5. 焊接组装：按照BOM清单焊接元件，完成功能测试

九、设计思维

设计思维（Design Thinking）是由斯坦福大学d.school提出的一种以人为本的创新方法论，强调从用户需求出发，通过跨学科协作和迭代测试不断优化解决方案。它不仅适用于产品设计，也广泛应用于服务设计、商业模式创新等领域。

设计思维的核心理念

  • 以人为本：始终站在用户角度思考问题，理解用户的真实需求和情感
  • 跨学科协作：汇聚不同背景的人才，碰撞出更多创意火花
  • 快速迭代：不追求一步到位，通过快速原型和测试不断改进
  • 拥抱失败：将失败视为学习的机会，鼓励大胆尝试

设计思维五步法

1. 共情（Empathize）—— 理解用户

通过用户访谈、观察、问卷调查等方法，深入了解用户的需求、痛点和期望。共情是设计思维的基础，只有真正理解用户，才能设计出有价值的产品。

常用方法：用户访谈、实地观察、问卷调查、用户画像（Persona）、用户旅程图（Journey Map）

2. 定义（Define）—— 明确问题

将共情阶段收集到的信息进行整理和分析，提炼出核心问题。好的问题定义应该具体、可操作，既不宽泛也不狭窄。

常用工具：问题陈述（How Might We）、HMW问题、设计简报（Design Brief）、需求优先级矩阵

3. 构思（Ideate）—— 发散创意

围绕核心问题，通过头脑风暴、思维导图等方法产生尽可能多的解决方案。此阶段强调数量而非质量，鼓励天马行空的想法。

常用方法：头脑风暴（Brainstorming）、思维导图（Mind Map）、SCAMPER法、六顶思考帽、逆向思维

4. 原型（Prototype）—— 快速验证

将创意转化为可触摸的原型，用最低成本快速验证设计思路。原型不必完美，关键是要能测试核心功能和用户体验。

原型类型：纸质原型、3D打印模型、功能样机、交互原型（Figma/Axure）、视频演示

5. 测试（Test）—— 收集反馈

让真实用户使用原型，收集反馈和建议。测试不是验证"设计是否正确"，而是发现"设计还有什么不足"。

测试方法：可用性测试、A/B测试、用户反馈表、行为观察、数据分析

设计思维与创客精神的结合

设计思维与创客精神高度契合，两者都强调：

  • 用户导向：从真实需求出发，而不是为了技术而技术
  • 动手实践：用实物原型验证想法，而不是停留在纸面讨论
  • 快速迭代：接受不完美，通过不断改进逼近最优解
  • 跨学科融合：结合技术、设计、商业等多维度思考

  • 执行模块: 5mm 高亮 LED 灯 × 1（单灯显示双传感器状态），220Ω 限流电阻 × 1
  • 接线与电源: 杜邦线若干，面包板 × 1，5V USB 供电

2. 自定义结构件说明

花盆主体结构为3D打印件，采用双层分体式设计：上层为多肉种植盆，下层为漏水收集与传感器安装仓；结构件预留了传感器探头安装孔、风扇通风口、显示屏与按键安装位，实现所有器件的一体化集成。

2. 核心功能说明

双土壤湿度采集：表层 + 深层；单 LED 亮度分级显示：全灭 = 两层都湿润；低亮 = 表层干燥；中亮 = 深层干燥；高亮 = 两层都干燥。支持 WiFi 连接 + Web 远程控制，自动 / 手动模式切换。

3. 核心嵌入式代码

#include <WiFi.h>

// ==================== 引脚定义 ====================
#define LED_PIN         2       // 状态LED
#define SOIL_SURFACE    0       // 表层传感器
#define SOIL_DEEP       1       // 深层传感器

// ==================== WiFi信息 ====================
const char* ssid     = "小母牛倒立";
const char* password = "niubichongtian";

// ==================== 湿度阈值 ====================
#define SURFACE_DRY  3200
#define SURFACE_WET  1800
#define DEEP_DRY     3000
#define DEEP_WET     1600

// ==================== LED亮度等级 ====================
#define L_OFF     0
#define L_SURFACE 85
#define L_DEEP    170
#define L_BOTH    255

WiFiServer server(80);
int currentBright = 0;
bool autoMode = true;

// ==================== 函数声明 ====================
int readSensor(int pin);
void setLED(int bright);

// ==================== 初始化 ====================
void setup() {
    Serial.begin(115200);
    ledcAttach(LED_PIN, 5000, 8);
    setLED(0);

    // WiFi连接
    WiFi.begin(ssid, password);
    while (WiFi.status() != WL_CONNECTED) delay(500);

    server.begin();
}

// ==================== 主循环 ====================
void loop() {
    // 自动模式：根据双传感器控制LED
    if (autoMode) {
        int sVal = readSensor(SOIL_SURFACE);
        int dVal = readSensor(SOIL_DEEP);

        bool sDry = sVal > SURFACE_DRY;
        bool dDry = dVal > DEEP_DRY;

        if      (sDry && dDry) setLED(L_BOTH);
        else if (dDry)         setLED(L_DEEP);
        else if (sDry)         setLED(L_SURFACE);
        else                  setLED(L_OFF);
    }

    // Web服务器处理
    WiFiClient client = server.accept();
    if (!client) return;

    String req = client.readStringUntil('\r');

    // 模式切换
    if (req.indexOf("GET /auto") >= 0) autoMode = true;
    if (req.indexOf("GET /manual") >= 0) autoMode = false;

    // 手动开关LED
    if (req.indexOf("GET /toggle") >= 0) {
        autoMode = false;
        currentBright = (currentBright == 0) ? 255 : 0;
        setLED(currentBright);
    }

    // 读取数据
    int sVal = readSensor(SOIL_SURFACE);
    int dVal = readSensor(SOIL_DEEP);

    // 简易网页
    client.print("HTTP/1.1 200 OK\r\nContent-Type: text/html\r\n\r\n");
    client.print("<h2>智能花盆</h2>");
    client.print("表层湿度: " + String(sVal) + "<br>");
    client.print("深层湿度: " + String(dVal) + "<br>");
    client.print("<a href='/auto'>自动模式</a><br>");
    client.print("<a href='/manual'>手动模式</a><br>");
    client.print("<a href='/toggle'>LED开关</a>");

    client.stop();
}

// 平滑读取传感器
int readSensor(int pin) {
    int sum = 0;
    for (int i=0; i<5; i++) { sum += analogRead(pin); delay(10); }
    return sum / 5;
}

// 设置LED亮度
void setLED(int bright) {
    currentBright = bright;
    ledcWrite(LED_PIN, bright);
}
